# Residential Unit Scheme 01 – CAD Floor Plan Layout

## Project Overview
This repository contains the 2D orthographic floor plan layout for **Residential Unit Scheme 01**. The drawing was created in accordance with South African architectural drafting standards (SANS 10400), featuring structured layer hierarchy, precise linear dimensioning, room annotations, door/window coding, and a completed A3 title block layout.

## Key Drawing Layers & Features
The CAD drawing is organized using distinct line properties and layers to ensure visual clarity:

* **`WALLS`**: Exterior 220mm double-skin brickwork and interior 110mm single-skin brickwork.
* **`OPENINGS`**: Doors (D1, D2) and Window schedules (W1, W2, W3).
* **`FIXTURES`**: Built-in kitchen double sink, bathroom tub, washbasin, and WC.
* **`DIMENSIONS`**: Chain and overall dimension strings defining room boundaries and wall thicknesses.
* **`ANNOTATIONS`**: Room function text labels, ceramic tile finish specs, and General Notes.
* **`TITLE_BLOCK`**: Standardized A3 border frame, north symbol, and metadata fields.

## General Notes & Compliance
All work complies with standard SANS 10400 building regulations. External masonry walls are 220mm double-skin brickwork, internal walls are 110mm single-skin brickwork, and wet areas feature ceramic tile finishes laid on waterproofed screed.
